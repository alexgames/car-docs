# Style Lab

Локальная браузерная доска карточек для проектирования идей по стилям CarDesign.
Прототип-редактор (нужен Chrome/Edge — File System Access API), сервер не требуется.

## Запуск

Открыть `index.html` напрямую в Chrome/Edge, нажать «Открыть папку data» и выбрать/создать
пустую папку — туда будут сохраняться JSON и фото.

## Структура

- **Стили** — 5 вкладок сверху (`styles.json`), у каждого свой заголовок и описание.
- **Разделы** — общий для всех стилей список (`blocks.json`): Recreate / Inspire / Wild Cards /
  Обвес / Сохранённые идеи / Лучшие работы игроков. Переименовали или добавили раздел
  (кнопка «+ Добавить раздел») — появилось сразу у всех 5 стилей, с пустыми данными; заполняются
  идеями по каждому стилю отдельно.
- **Идея** — карточка с 1–3 фото (drag&drop из Finder, клик, или из базы Car DB), текстом
  и подписью кнопки (по умолчанию берётся из раздела, можно переопределить). У каждого фото
  свои опциональные флаг/заголовок/описание. Внизу карточки — опциональный счётчик
  «собрано машин» (иконка 🚗 + число).

## Фото из базы Car DB

В карточке идеи, под зоной перетаскивания, есть кнопка «📚 добавить фото из базы Car DB» —
открывает список машин из [Tools/car-db](../car-db), с выбором ракурса. Фото при этом
**копируется** в идею (не живая ссылка), плюс подтягиваются флаг/название/короткое описание
машины — можно сразу поправить.

Папка с базой Car DB выбирается **один раз, отдельно** от папки data самого style-lab (кнопка
«Открыть папку с базой Car DB…» внутри этого же диалога) — не обязательно, чтобы это была та же
папка, инструмент запоминает её самостоятельно.

## Данные на диске

```
data/
  blocks.json                 — шаблон разделов, общий на все стили
  styles.json                 — 5 стилей: заголовок + описание
  _meta.json                  — счётчик id идей
  ideas/<style>/<block>/<ideaId>.json
  images/<style>/<ideaId>/1.jpg, 2.jpg, 3.jpg
```

## Дальше (не реализовано)

Экспорт данных в готовую HTML-страницу для игры: мобайл-ландшафт, шапка с описанием стиля,
тайловый фон-чертёж, ряды карточек по разделам. Схема данных выше рассчитана на то, чтобы
такой рендер было легко написать отдельным скриптом поверх `data/`.
