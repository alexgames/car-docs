# Car DB

Локальная база карточек-машин с редактором пропорций. Отдельный инструмент — не привязан
к style-lab напрямую, можно использовать для любых задач. Прототип-редактор
(нужен Chrome/Edge — File System Access API), сервер не требуется.

## Запуск

Открыть `index.html` в Chrome/Edge, «Открыть папку data» → выбрать `Tools/car-db/data`
(уже создана и лежит рядом с `index.html`; если открывать впервые в другом месте —
можно создать новую пустую папку где угодно).

## Код

`index.html` — только разметка и подключения. Сам код разбит по смыслу (2026-09,
раньше был один файл ~1800 строк):

```
css/style.css     — весь CSS
js/app-core.js    — App.Const, App.State, App.FS (File System Access), App.Drag
js/app-data.js    — App.Data: машины, фото, метрики пропорций, дефолты
js/app-ui.js      — App.UI: весь рендеринг (список машин, форма, холст, легенда)
js/app-boot.js    — renderAll, loadFolder, обработчики кнопок, восстановление папки
```

Порядок `<script>` в `index.html` важен — каждый файл использует глобалы из
предыдущего. Все скрипты классические (не `type="module"`), поэтому работает и через
двойной клик по `index.html` (`file://`), и через локальный сервер — модули под
`file://` браузер не грузит из-за CORS, обычные скрипты и стили — грузит. Если
`index.html` нужно передать отдельно от папки — файлы `css/`/`js/` придётся взять с
собой; либо склеить всё обратно в один файл (быстрее, чем резать было).

## Анализ пропорций

Чтобы пересчитать абсолютную разметку всех карточек в относительные величины:

```bash
node analyze-proportions.mjs
```

Скрипт не изменяет карточки и создаёт два производных файла в `analysis/`:

- `proportions.csv` — удобен для таблицы и ручной сортировки;
- `proportions.json` — метрики, заметки о данных и геометрические
  кластеры для дальнейшего анализа.

Все продольные размеры делятся на длину `head → trunk`, вертикальные — на высоту
`ground → top`. Автоматический кластер — только
аналитическая подсказка; продуктовая принадлежность машины должна храниться отдельно.

## Как это используется из style-lab

Не нужно открывать одну и ту же папку в обоих инструментах. В style-lab, в карточке идеи,
есть отдельная кнопка «Открыть папку с базой Car DB…» — там один раз указываешь путь к этой
самой `data/` (см. выше), она запоминается отдельно от собственной папки style-lab. Дальше
из идеи можно выбрать машину → ракурс, фото скопируется в идею вместе с флагом/названием.

## Модель

- **Машина** — карточка: название (марка-модель-год), стиль/подстиль (свободный текст),
  связи использования (стиль → категория / задание, несколько), описания (короткое,
  историческое), страна, дизайнер, ширина карточки (из общего набора пресетов).
- **Ракурсы**: side (силуэт сбоку — рабочий, с разметкой), front, 3/4 front, 3/4 rear,
  rear, + 2 доп. ракурса с переименовываемым названием.
- У каждого ракурса: **драфт** — список фото для работы в редакторе (любые имена),
  **финал** — одно фото, которое реально идёт в билд. У каждого фото — своя позиция
  (x/y/масштаб) на холсте.
- **Разметка** (5 вертикальных линий head/cab1/center/cab2/trunk + 4 горизонтальных
  ground/bottom/center/top) — только у ракурса side. Хранится как смещение от
  фиксированной центральной линии / линии пола, не от фото. В экспорт не попадает —
  это рабочий инструмент редактора.
- **Экспорт** — по кнопке печёт плоский PNG (без слоёв/смещений) шириной = ширина
  карточки машины, высотой = высота холста, из активного фото (приоритет — финал).
  Кладётся в `photos/<carId>/<view>/export.png`. Галочка «показать финал поверх» —
  накладывает его полупрозрачно на холст для сверки.

## Данные на диске

```
data/
  cardSizes.json                       — общий список ширин карточки (один на все машины)
  cardDefaults.json                    — стартовые разметка/ширина карточки/стиль/подстиль для НОВЫХ
                                          машин (кнопка «Карточка по умолчанию» в легенде
                                          разметки); нет файла — используются встроенные
                                          дефолты. Старый guideDefaults.json (только разметка,
                                          без ширины/стиля) читается как миграция, если
                                          cardDefaults.json ещё не создан
  _meta_cars.json                      — счётчик id машин (отдельное имя — чтобы не
                                          конфликтовать со style-lab при общей папке)
  cars/<carId>.json                    — вся карточка целиком (поля + разметка)
  photos/<carId>/<view>/draft/<n>.ext  — черновые фото
  photos/<carId>/<view>/final.ext      — финальное фото ракурса
  photos/<carId>/<view>/export.png     — экспортированная карточка
```

## Упрощения v1 (можно расширять по мере надобности)

- Стиль/подстиль/связи использования — свободный текст, не читаются из style-lab.
- У линий разметки один флаг видимости (был план сделать отдельно «видимость в финале»,
  но раз финал — чистое фото без линий, второй флаг был не нужен).
- Масштаб фото на холсте выставляется автоматически по высоте при загрузке,
  ручного зума пока нет — только позиционирование (drag).
- Ширина карточки — один пресет на машину (не отдельно на ракурс); экспорт всех
  ракурсов ориентируется на него.
