# Экономика игры: что выяснили и в каком порядке действовать

Связано с: [[Методология баланса — рекап исследования]] · [[Рынок — цены IAP и реклама]] · [[Референс-игры/BowMasters]] · [Balance Lab](../../Tools/balance-lab/)

## Зачем этот документ
Собрали методологию (что почитали), рыночные ориентиры (что почитали + нашли по реальной игре) и уже готовый инструмент для проверки (Balance Lab). Дальше — не "ещё почитать", а конкретная последовательность действий, чтобы прийти к согласованным ценам, а не к очередному раунду переписки.

## Что уже точно выяснили (не гипотезы, факты/сильные находки)

1. **Магазин, похоже, скопирован с BowMasters по структуре.** Названия товаров (`pinchgems`, `pocketcoins`...) совпадают с форматом BowMasters ("Pinch of Gems"). ⚠️ *Поправка: конкретное сравнение цен ($5 vs $1.99) снято — владелец уточнил, что `static_prices.csv` содержит округлённые цифры для расчётов, не боевые цены (в реальном магазине уже .99).* Осталось проверить: есть ли в реальном магазине входной тир $0.99-1.99, как у BowMasters — у нас в конфиге его нет. См. [[Референс-игры/BowMasters]].
2. **Кристалльная экономика течёт** (правило "сток должен быть чуть больше источника" нарушено): реклама даёт ~9 кристаллов/день, а весь кристалльный контент, который целевой профиль вообще пытается купить — 2850. Одной рекламы хватает закрыть его за ~10 месяцев, не трогая остальные источники.
3. **Буст конкурирует с контентом за тот же кристалльный faucet** — в прогоне гипотезы буст не ускорил, а замедлил прогресс профиля (забирает кристаллы, которые иначе пошли бы на контент).
4. **Лимит рекламы (3/день) ниже даже самой консервативной индустриальной нормы** (8-12/день для хардкор-игр) — но поднимать его нельзя раньше, чем пересчитана ставка за ролик, иначе усугубит находку №2.
5. **У нас нет метрики "сколько мы реально зарабатываем на показе рекламы"** (eCPM × показы) — только "сколько отдали игроку в $-эквиваленте". Это разные вещи, вторая половина картины пока не считается.

## Порядок работ (по шагам, каждый разблокирует следующий)

### Фаза 1 — Магазин (реальные .99-цены уже стоят, конфиг — только для расчётов)
- [ ] Проверить, есть ли в реальном магазине входной тир $0.99-1.99 (в конфиге для расчётов его нет).
- [ ] Свериться с BowMasters (и, по возможности, ещё 1-2 похожими играми) по нижним тирам, когда будут реальные цены под рукой.

### Фаза 2 — Хард-валюта (кристаллы) — самое горячее место, начинать первым по экономике
- [ ] Владельцу/геймдизайнеру решить: **какой % кристалльного контента бесплатный "умеренный" игрок должен закрывать за полгода-год** (не 100% — так теряется причина платить). Это единственное число, которое нельзя вычислить, только продуктово решить.
- [ ] От этого числа посчитать назад допустимый `gemsPerAd` (метод в [[Методология баланса — рекап исследования]], шаг 6).
- [ ] Отдельно решить роль буста: либо развести его источник финансирования от контента (не тратить те же кристаллы), либо явно принять, что буст приоритетнее контента, и заложить это в расчёт.
- [ ] Прогнать через Balance Lab (профили + гипотезы), проверить, что цифры сошлись.

### Фаза 3 — Софт-валюта (монеты)
- [ ] То же самое, но для монет — целевой срок для казуала уже неплохо сходится (~0.88 текущее соотношение потрачено/заработано), тут скорее подтвердить, не пересчитывать с нуля.
- [ ] Разложить цену контента по категориям крещендо-кривой (сейчас `styles` растёт правильно, `tools` — падает, `extra` — плоско — см. рекап методологии).

### Фаза 4 — Реклама: доход студии
- [ ] Добавить в Balance Lab вторую метрику: `$ заработано на рекламе` (не только "$ отдано игроку") — формула `показы × eCPM/1000`, eCPM — новый параметр конфига.
- [ ] Только после Фазы 2 (ставка за ролик пересчитана) — поднимать дневной лимит показов к индустриальной норме (8-15/день в зависимости от жанра).

### Фаза 5 — Референс-игры (доп. проработка, не блокирует остальное)
- [ ] BowMasters — сделан только внешний teardown (цены из стора). Полный разбор (сколько дают паки кристаллов, темп открытия персонажей) требует реально поставить игру и пройти первые часы — отдельная задача, если нужна глубина, не только цены.
- [ ] Найти ещё 1-2 игры с похожей структурой (открываемые юниты + апгрейды + два вида валюты) для второго/третьего референса — не полагаться на один источник сравнения.

## Открытые вопросы — только владелец/геймдизайнер могут решить (не техническая задача)
1. Целевой % закрытия кристалльного контента бесплатным игроком за полгода-год (см. Фаза 2).
2. Роль буста — часть контентной экономики или отдельная приоритетная механика.
3. Целевой географический профиль аудитории (США tier-1 vs остальной мир) — сильно меняет ожидаемый доход с рекламы (eCPM $15-25 vs $3-10), а значит и то, сколько разумно раздавать бесплатно.
