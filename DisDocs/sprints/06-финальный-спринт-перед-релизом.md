# Финальный спринт перед релизом

Связано с: [Текущий спринт: сборка](01-текущий-спринт-сборка.md) · [Спринт концепции 2.0](05-следующий-спринт-концепция-2.0.md) · [План тестирования](../07-план-тестирования.md)

Сейчас делается тестовая версия — эти задачи не нужны для неё, но обязательны перед реальным релизом. Собраны в одном месте, чтобы не потерялись между другими документами.

## 1. Баннер, когда Арена пустая
Картинка/подиум + таблица наград + инфо-кнопка + ранг игрока — см. [[05-следующий-спринт-концепция-2.0]], раздел "UI-мелочи".

## 2. Баг с туториалом
Кнопка "Далее" кликабельна на шаге размещения обвеса, хотя визуально неактивна — см. [[01-текущий-спринт-сборка]], пункт 4.

## 3. Стартовый экран
Крестик выхода, текстовая подпись — см. [[01-текущий-спринт-сборка]], пункт 3.

## 4. Доработка дизайна интерфейса (сейчас тестовый)
Текущий UI сделан как тестовый/функциональный, не финальный по дизайну — довести до релизного вида перед запуском. Не детализировано дальше, отдельная задача на момент, когда до неё дойдёт очередь.

## 5. Проверка апдейта старых пользователей (совместимость)
Часть активных пользователей откроет игру со старым сохранением/прогрессом после сильно изменившегося геймплея — риск краша/потери прогресса. Полный чеклист уже есть — см. [[../07-план-тестирования]], раздел 2 "Обновление со старых версий".

## 6. Обвесить новые фичи статистикой
Все новые механики версии 2.0 (экран выбора режима, ПРО, промокоды, дейлики) должны логировать события для аналитики до релиза — иначе после запуска не будет данных о том, что реально используется. Проверить по каждой новой фиче из [[05-следующий-спринт-концепция-2.0]] и связанных гипотез ([[../hypotheses/13-про-режим-создай-свой-стиль]], [[../hypotheses/14-промокоды-чертеж-паззл]]).
