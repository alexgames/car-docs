# Описание

Параметрический редактор для быстрого создания фар и решёток, а позднее — деталей для игрока.

Первый этап — внутренний authoring-инструмент в отдельной Unity-сцене. Деталь собирается внутри одного корневого объекта, редактируется через Scene View и кнопки инспектора, после чего сохраняется как prefab. Математическое ядро не должно зависеть от `UnityEditor`: позже тот же движок можно будет вызвать из игрового инструмента.

Цель прототипа — не универсальный 3D-редактор, а несколько простых и выразительных принципов построения, из которых можно быстро сделать реальные детали для игры.

### Контур: первое техническое решение

- Контур хранится в локальной 2D-плоскости корневого объекта.
- Пользователь редактирует только опорные точки.
- Для сглаживания используется замкнутый centripetal Catmull–Rom (`alpha = 0.5`): он меньше склонен к петлям и выбросам, чем uniform-вариант.
- `Smoothness = 0` показывает ломаный polygon, `Smoothness = 1` — полное сглаживание. Реализация может смешивать линейный сегмент и результат Catmull–Rom.
- У каждой точки есть режим `Smooth` или `Corner`. `Corner` сохраняет явный угол и позволяет строить прямоугольные и трапециевидные фары.
- Количество preview-сэмплов сначала фиксированное на сегмент; адаптивное разбиение по кривизне можно добавить позже.
- Исходные точки являются авторитетными данными. Preview и итоговые меши всегда генерируются заново и не редактируются вручную.
