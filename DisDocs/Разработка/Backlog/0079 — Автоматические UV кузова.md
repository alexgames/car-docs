# Описание

Автоматически генерировать приблизительные UV для кузова без ручной развёртки. Основная цель — использовать обычные тайловые текстуры в материалах `URP/Lit` без обязательного трипланарного шейдера.

Задача отложена: сейчас продолжаем генератор фар и решёток.

## Продуктовый результат

- Дерево, металл, резина, ткань, декоративные и шуточные материалы можно применять к кузову как обычные тайловые текстуры.
- Материалы не обязаны иметь отдельный трипланарный вариант.
- Плотность текстуры должна быть одинаковой на разных кузовах и деталях.
- Трипланар остаётся специальным вариантом для материалов, на которых заметны швы.

## Техническое решение

Первый прототип — «запечённая box-проекция»:

1. Для каждого треугольника определить доминирующее направление нормали.
2. Выбрать плоскость проекции `XY`, `XZ` или `YZ`.
3. Рассчитать UV из локальных координат с общей настройкой размера одного тайла.
4. Разделить вершины на границах разных проекций, поскольку одна вершина не может иметь несколько UV.
5. Не упаковывать острова обязательно в `0…1`: тайловая текстура использует режим `Repeat`.
6. По возможности размещать швы на жёстких рёбрах и границах деталей.

Это аналог выбора проекции в трипланаре, но рассчитанный один раз и записанный в меш. В шейдере после этого остаётся обычное чтение UV.

## Когда пересчитывать

При обычной деформации пересчёт не требуется: топология не меняется, UV двигаются вместе с вершинами.

Пересчитывать только когда:

- заменён кузов или его часть;
- изменена топология комбинированного меша;
- вырезано отверстие;
- создана новая сглаженная сетка с другими вершинами;
- изменился алгоритм UV или плотность тайлинга.

Можно запускать генерацию при входе в работу с материалами. Допустимая задержка — несколько секунд, хотя простая box-проекция должна занимать миллисекунды или десятки миллисекунд. Основная стоимость — создание новых массивов и разделение вершин на швах.

## Кэш

Ключ кэша:

`идентификатор топологии + версия UV-алгоритма + плотность тайлинга`

Рассчитанные UV желательно хранить на уровне исходных `MeshUnit` и переносить в комбинированный меш, а не генерировать при каждом входе в инструмент.

## Ограничения

- На переходах между плоскостями будут UV-швы.
- Для направленных текстур — карбона, полос, древесных волокон — понадобится настройка ориентации проекции по части или материалу.
- Автоматические box UV подходят для тайловых материалов, но не заменяют полноценную развёртку для уникальной покраски всей машины.

Для будущего режима уникального рисования можно исследовать `xatlas`: он создаёт полноценные UV-острова, но добавляет швы и дублированные вершины. Декали и vertex colors остаются отдельными средствами для рисунков, масок, оттенков и градиентов.
