Попап получения Награды


Можно кстати кнопку для **регистрации по емейл** и прислать сразу деталь готовую. Но надо чтобы было понятно что это не еще один код а сразу эксклюзивная деталь - лид магнит.




Ответ от сервера
true. Тип чертежа (id = body, tuning), количество открытых частей, всего частей, если все открыто - награда (тип = body, tuning, подтип (head, cab1... fara, grill), Id = 107 ). Может быть открыта награда без открытия паззла (для промо)

Вопросы по серверу
Список кодов хранится на сервере. Наверное стоит сделать в базе тк коды имеют дату публикации.
Сервер генерит еще коды по запросу маркетингового скрипта хотя можно локально сгенерить пару тысяч
Отдает список не использованных, с лимитом. Хотя пока можно чтобы скрипт сам запоминал.
Маркетингового скрипт отдает даты публикации роликов серверу.
Не знаю хранить ли кусочки, можно наверное доверять клиенту.

На сервере есть списки наград двух типов (отдельные).
Надо предусмотреть если какойто список закончился.
Вероятно при старте игры стоит запросить доступность наград. Или вернуть в startSession. Награды могут добавиться так что надо иногда обновлять.
