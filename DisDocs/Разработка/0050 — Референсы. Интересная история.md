## Idea — это не режим, а библиотека отправных точек

Внутри Idea со временем действительно могут появиться:

- конкретная машина;
- отдельная деталь;
- сочетание деталей;
- коллаж из нескольких машин;
- дизайнерский принцип;
- короткий урок;
- упражнение с ограничениями;
- бывший Daily, достойный сохранения.
- 
главное — не формат исходного материала, а то, что игроку предлагается сделать.

Например:

- `Classic Proportions` — изучить пропорции;
- `Split Grille` — попробовать конкретный приём;
- `Rally + Luxury` — соединить два образа;
- `1960s Coupe` — интерпретировать машину;
- `Wide Body` — упражнение с заданными деталями.

Так раздел не устареет, когда вы выйдете за пределы простых автомобильных фотографий.

### Inspiration
Игроку дают изображения или краткое направление, но ничего не ограничивают.

### Guided

Идея сопровождается небольшим учебным акцентом:

```
Материалы: картинки + дизайнерский принцип
```

### Challenge

Идея становится заданием с условиями:
```
Редактор: модифицированный
```
```
Ограничения: фиксированные или разрешённые детали
```
```
Цель: решить задачу в заданных рамках
```
Например:

- сохранить заданный кузов;
- использовать конкретный обвес;
- выбрать детали только из двух стилей;
- не менять пропорции кабины;
- применить промодеталь;
- собрать машину из ограниченного набора элементов.

Таким образом, **не для каждого референса нужен отдельный конфиг**. Обычная идея работает на настройках по умолчанию. Конфиг появляется только там, где он действительно добавляет ценность.

То есть контент-редактор выбирает готовые правила:

- `Open`;
- `Fixed body`;
- `Limited parts`;
- `Required parts`;
- `Extra tool`;
- `Step-by-step`;
- `Promotional parts`.

А индивидуально переопределяет только необходимое. Возможность глубокой настройки остаётся, но не становится обязательной ценой публикации каждой идеи.

**Можно дать возможность игроку самому сохоанять дейлики в рефы**;

## 6. Урок и референс не должны быть отдельными мирами

Референс может быть уроком. Урок может состоять из нескольких референсов. Лучше мыслить карточку как «идею», имеющую опциональные слои:

```
IDEA
├── визуальные материалы
├── дизайнерский принцип
├── инструкции
├── ограничения
├── дополнительные инструменты
├── награда
└── правила публикации
```

я могу **менять деформации, но не давать игроку выбор**. Тогда это интересная задача. Те же формы, но совсем другие машины; (обычные деформации ограничены и не дают таких возможностей.

Поэтому Daily лучше строить преимущественно через:

- необычные стартовые деформации;
- заранее установленную деталь;
- необычное сочетание частей;
- специальную промодеталь;
- ограниченный набор, когда ограничение очевидно является сутью задания.

Не обязательно показывать игроку длинный список правил.


Для всех стилей
Деревянная машина
Машина из сыра
Полосатая
Градиент (нельзя менять)
Задание по формам (треуг/квадрат/круг)
