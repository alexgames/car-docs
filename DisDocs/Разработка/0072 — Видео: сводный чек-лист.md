Делегирование (Android-сборка для исполнителя) — **отложено**, ролики пишет владелец лично, план "1 ролик/день весь год". Инструмент записи при этом всё равно нужен и развивается — просто без делегирования пока. Контент-конвейер (inspiration/01) — активная, но не приоритетная задача: раньше баланса/тестирования кора не начинается.

## Чек-лист — ОБЩЕЕ (движок записи, нужен и в игре, и в редакторе/спец-сборке)

- [ ] **Реплей записывает каждый кадр, не только ключевые события** — сейчас записываются только ключевые (0020). Нужно решить, как ужать файл при полной покадровой записи.
- [ ] **JSON-реплей вместо PNG-секвенции** — конфиг по кадрам (что изменилось + положение камеры), не сырые кадры. Уже спроектировано для делегирования (sprint 04), нужно распространить на обычную запись (inspiration/01).
- [ ] **Интерполяция движения камеры** — не писать каждый кадр камеры буквально, апроксимировать с нужной точностью (0020, старая заметка "Реплей.md": "сглаживать реальное движение, а не инпут").
- [ ] **AVPro Movie Capture (Mobile Edition, $300)** — плагин выбран, технический план готов: `RenderTexture → AVPro → MP4`, `CaptureFromTexture` с `IsManualUpdate=true` и `IsRealTime=false`, кадр коммитится вручную через `UpdateSourceTexture()` только когда реплей решил, что кадр готов (Backlog/0018 — самое конкретное из всех доков, уже почти готово к реализации).
- [ ] **Автомонтаж по шаблону** — скрипт выбирает лучшие кадры из полного реплея (самые большие изменения, смена цвета, редкие детали, красивые ракурсы, финальный reveal) — 0020, 0019 ("АВТОМОНТАЖ ролика по шаблону").
- [ ] **Библиотека сценариев/шаблонов монтажа** — собрать полный список форматов (используя банк идей маркетинга), выбрать простые для первой версии (inspiration/01, sprint 04 п.1).
- [ ] **Разные форматы экспорта из одного реплея** — вертикально/горизонтально/квадрат/TikTok/YouTube/реклама — один и тот же JSON пересобирается под любой формат без пересъёмки (0020).
- [ ] **Отдельная камера съёмки, не Workshop-камера** — орбитальная камера игрока хороша для осмотра, плоха для монтажа/задников. Нужен `Photo/Video Camera` с фиксированными пресетами ракурсов (front, 3/4, side, rear), отдельными pan/zoom/DOF — это и есть "камеры, которые не видит игрок": рендер-камера для видео работает независимо от того, что игрок видит на экране во время игры (Backlog/0022).
- [ ] **Гараж/сцена-фон для видео** — фича **уже реализована в игре, но выключена**; нужно включить + добавить выбор/покупку (inspiration/01). Пересекается с [0036 — Фотофон.md](Backlog/0036%20—%20Фотофон.md).
- [ ] **Промокод, вклеиваемый в готовую секвенцию постфактум** — не пересъёмка, обогащение уже отснятого (inspiration/01, опционально, только если базовая версия игры заработает).
- [ ] **Юридическое: право использовать контент игрока для рекламы** — нужна формулировка в Terms/лицензии, с юристом при коммерческом использовании (0020).

## Чек-лист — ТОЛЬКО РЕДАКТОР / спец-сборка для исполнителя (delegation-инструмент, отложено, но специфицировано)
- [ ] Отдельная Android-сборка, вертикальная, защищённая паролем, без раскрытия исходников/основного продукта.
- [ ] **Панель управления записью**: настройки + кнопка старт/стоп (sprint 04).
- [ ] Запись полного конфига по кадрам (камера + всё остальное) именно в этой спец-сборке.
- [ ] Приёмка на сервере: загрузка JSON, отсмотр и отбор владельцем — рендер/монтаж/постинг дальше не меняются.
- [ ] Простая инструкция для исполнителя (не требует компетенции).
- [ ] Экономика уже посчитана: ~200 ₽/ролик, ~6000 ₽ за 30 роликов — держать при возврате к задаче.
- **Условие возврата к этой ветке:** делегирование возобновляется, если самостоятельная запись владельцем не выдерживает темп или появятся деньги на помощника (sprint 04).
