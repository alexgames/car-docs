## Чек-лист — ОБЩЕЕ (движок записи, нужен и в игре, и в редакторе/спец-сборке)

- [x] **Компактный replay вместо покадровой записи полного состояния** — стартовый `CarData`, дискретные события и упрощаемые motion-треки камеры, тюнинга и деформа.
- [ ] **CarStateResolver с произвольным seek** — восстановить машину на любом времени реплея, в том числе при движении ползунка назад (0090).
- [ ] **Video Shot отдельно от Replay** — реплей хранит факты игры, Shot задаёт постановочное вращение, замену деталей, плавную деформацию, камеру, `LookAt` и скорость монтажа (0090).
- [x] **Трек игровой orbital-камеры** — интерполируются `yaw/pitch/distance` и записанный pivot; live target не используется.
- [ ] **Постановочные Camera Pose/LookAt keys** — для smart orbit без ручного spline.
- [ ] **SmartCameraRig** — fit/orbit/focus с расчётом по bounds конкретной машины, safe frame и объекту внимания (0090).
- [ ] **AVPro Movie Capture (Mobile Edition, $300)** — плагин выбран, технический план готов: `RenderTexture → AVPro → MP4`, `CaptureFromTexture` с `IsManualUpdate=true` и `IsRealTime=false`, кадр коммитится вручную через `UpdateSourceTexture()` только когда реплей решил, что кадр готов (Backlog/0018 — самое конкретное из всех доков, уже почти готово к реализации).
- [x] **Монтаж по шаблону** — есть фиксированный и автоматический planners, silent-применение пропущенного состояния и montage reports.
- [ ] **Библиотека сценариев/шаблонов монтажа** — собрать полный список форматов (используя банк идей маркетинга), выбрать простые для первой версии (inspiration/01, sprint 04 п.1).
- [x] **Output frame/layout как отдельная настройка** — 3:4 и другие размеры можно пересобирать из одного replay; есть preview и режимы Standard/Deform/Tuning.
- [x] **Game/Video/Recording cameras разделены по ролям** — рендер-камеры формируют output независимо от Game View.
- [ ] **Production main recording camera** — автоматический framing по bounds и safe frame.
- [ ] **Orbit recording camera** — набор умных проходов, адаптирующихся к размеру машины.
- [ ] **Гараж/сцена-фон для видео** — фича **уже реализована в игре, но выключена**; нужно включить + добавить выбор/покупку (inspiration/01). Пересекается с [0036 — Фотофон.md](Backlog/0036%20—%20Фотофон.md).
- [ ] **Промокод, вклеиваемый в готовую секвенцию постфактум** — не пересъёмка, обогащение уже отснятого (inspiration/01, опционально, только если базовая версия игры заработает).
- [ ] **Юридическое: право использовать контент игрока для рекламы** — нужна формулировка в Terms/лицензии, с юристом при коммерческом использовании (0020).
