**Комментарии**

Нужно создвать отдельный инструмент (в новой вкладке).
Это будет как база данных карточек, как для романа.
С разметкой пропорций.
Ей можно пользоваться и далее для любых задач, помечать использование, добавлять новые, собирать их низ щадания или менять описание стиля.

Название (марка-модель-год)
Стиль (Компакт, Америка)
Подстиль (Fin tail, Muscle)
Cвязи с использованием: Compact → Inspire, America → Wild Cards, конкретное задание и т.д.
Описание дизайна (короткая, округлая
Описание историческое
Страна происхождения
Дизайнер или дизайн-бюро (необязатльно)
Драфт фото - списко (для использования в редакторе - любое название)
Список финальных фото по маске (название-вид side, front, 34front, 34 rear, rear, custom1, custom2)
Конфиг с разметкой (пропорции, диагонали и прочее - json) относительно центральной линии и пола (не меняется)
Размер карточки (из набора - несколько вариантов ширины);

Можно начать с бокового вида (силуэт), с которым будет работа. Дополнительные фото-ракурсы просто добавляются для референсов. Их тоже можно располагать в редакторе, уже без разметки.
То есть для фото (ракурса) будет - драфт (используется только в редакторе), финал - идет в билд, и формат карточки (из списка вариантов).

**=Редактор карточек=**
Зафиксорованная высота холста, Бесконечный холст по горизонтали.
Центральная линия.
Зафиксорована линия пола.
Тогда размеры карточек будут задаваться только шириной. Ее можно подобрать и потом.
Нужен затем экспорт карточки с учетом карточки (разной ширины). Нужен файл уже без смещений.
Опция показать фото фильльную (уже экспортированную)

Слева - список карточек.
Создать карточку.
Открытая карточка с полями для заполнения и куда перетаскивать фото.

Пропорции вертикальные/горизонтальные.
Вертикальные линии двигаются точками/кнопками, также есть кнопка показать/скрыть.
head, cab1, center, cab2, trunk. Center может не совпадать с центом фото.
Для них нужно созранить только смещение от центра фото по Х.
Для финального рисовать могут быть другие параметры отображения.

Горизонтальные линии - ground совпадает с землей, но на всякий случай тоже другиется.
bottom, center, top. Точки кнопки для драга могут быть по центру и линии идут горизонтально на весь холст.
и вкл/выкл линию (для отображения финального).
