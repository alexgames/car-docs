# Концепция версии 2.0

Связано с: [Описание проекта](00-описание-проекта.md) · [Роадмап на год](01-роадмап-год.md) · [Баланс и монетизация](sprints/баланс-и-монетизация.md) · [Спринт реализации](sprints/05-следующий-спринт-концепция-2.0.md)

Полный бриф от владельца, зафиксирован как текущая целевая концепция. Заменяет более раннее решение этого же дня про последовательное открытие стилей с нарративным гейтом (Storyline/Orders/звёзды) — см. "Что меняется" ниже.

## Главная задача версии 2.0
Создать сильное ядро игры, которое: интересно само по себе; удерживает игроков; уже содержит рабочие точки монетизации; позволяет развивать проект небольшими обновлениями без перестройки архитектуры. После выхода фокус смещается на маркетинг, аналитику и проверку гипотез монетизации.

## Диагноз из отзывов (владелец прочитал отзывы в сторе, 2026-07-17)
- Игрокам не нравится пейвол — **решение: пейвола не будет вообще**.
- Долгий путь в реальную игру через обучение и ненужные уровни, не соответствующие роликам (рекламе) — причина плохих первых впечатлений.
- Слишком мало деталей на старте — уже исправлено (см. [[sprints/05-следующий-спринт-концепция-2.0]], разделение апгрейд/Экстрас).
- Отдельно (не из отзывов, собственное наблюдение владельца): реальная проблема сейчас — **"страх чистого листа"**, игрок не понимает, что делать в свободном редакторе. Решение — Референсы + Академия (ниже), не нарративный гейт.

## Кор-геймплей
Стиль → Создание машин → Арена → Монеты → Новые стили → Апгрейды → Новые возможности

## Что входит в версию 2.0

### Workshop
Основной режим игры. Открыт практически сразу — соответствует тому, что игрок видел в роликах.

### Стили
Каждый стиль — самостоятельный опыт: свой набор деталей, свои пропорции, своя система деформаций, своя эстетика, обучение через примеры. Апгрейд стиля открывает новые детали, деформации, дополнительные возможности внутри стиля.

### Референсы 💡
Во время создания машины — окно с фото реальных автомобилей выбранного направления. Вдохновение, понимание языка стиля, повторение понравившихся решений. Листается прямо во время работы, не выходя из Workshop.

### Референсы — обнаружение и смысл (решено 2026-07-18)
Порядок первого запуска: туториал (учит пользоваться редактором, собрать машину **по чертежу** — есть оценка/цель) → Workshop с туториал-стрелкой на кнопку Create → уровень открывается, референсы можно открыть сразу.

⚠️ **Найденный риск:** в туториале фото/чертёж — это оцениваемая цель ("повтори точно"). Если в Create референсы визуально похожи, игрок может решить, что это снова задание с оценкой — фантомное обязательство, которое возвращает тот же стресс, от которого уходим. Это не вопрос "объяснить два способа использования" (точное повторение vs общее вдохновение — это материал для будущей Академии, не для первого знакомства), а вопрос **явно показать, что это не оценивается**.

**Решение — визуально, без текста-объяснения (текст никто не читает):**
- Иконки-метафоры "идея/вдохновение" (лампочка, звёздочки) вокруг фото вместо текстового объяснения — сигнализирует "это вдохновение", не "это цель", одним взглядом.
- Короткая фраза-приглашение при первом показе (например "Вдохновись классическим дизайном"), не инструкция.
- Следующее фото частично видно из-за края экрана — универсальный сигнал "можно скроллить" без слов.
- Не учить двум способам использования референсов в v1 — не обязательно для первого знакомства, оставить для Академии позже.

### Академия — отложена, следующая версия (решено 2026-07-18)
Не входит в v1. В v1 "страх чистого листа" закрывают только Референсы + подсказки выше. Академия (дизайн-бриф, пропорции, приёмы, советы по использованию референсов) — реальная новая работа по контенту (не переиспользование старых ассетов, как было с нарративом), делать после подтверждения основного цикла.

### ПРО — новое позиционирование найдено, реализация после проверки кора (обновлено 2026-07-19)
2026-07-18: ПРО было решено не включать в v1 целиком — ни контентная, ни инструментальная ценность режима не были готовы. 2026-07-19: найдено содержательное позиционирование — **"создай свой стиль"**, не "смешение стилей": универсальные (не заточенные под конкретный стиль) схемы деформации + все открытые детали, платные инструменты, бесплатный вход после открытия 3 стилей. Подробности — [[hypotheses/13-про-режим-создай-свой-стиль]]. Реализация — после проверки основного цикла (экран выбора режима + Референсы), см. [[sprints/05-следующий-спринт-концепция-2.0]], "Порядок работы".

### Арена
Основной источник долгосрочного прогресса: публикация машин → монеты → развитие коллекции → новый контент.

### Экономика
Строится вокруг монет, кристаллов, открытия стилей, апгрейдов стилей. Версия 2.0 должна содержать несколько независимых точек монетизации, чтобы после релиза проверить, какие реально востребованы — см. [[sprints/баланс-и-монетизация]].

**Решено 2026-07-18: не вводить новый платный тир стилей в v1.** Реального дохода в старой версии не было измерено — была лишь проверка работоспособности платежей, не спроса (пейвол Workshop тестировал техническую работу IAP, не готовность платить за конкретный контент). Данных недостаточно, чтобы обоснованно решить, какая доля контента должна стать платной — вводить это сейчас означает повторить тот же риск "слишком много платного", ради ухода от которого убрали пейвол. Текущая структура (свободное открытие за монеты + $2 премиум-машина на стиль + апгрейды за кристаллы) — уже несколько независимых точек, это и есть реальный A/B-тест, только в проде после релиза, а не выдуманный заранее. Платный тир стилей — рычаг на будущее, если реальные данные покажут нехватку монетизации, не решение сейчас.

⚠️ **Открытый риск для баланса:** апгрейды (100-300 кристаллов) при доходе 30 кристаллов/день с рекламы закрываются F2P-игроком за 3-10 дней — рискует не ощущаться как долгосрочная цель. Нужно свериться при финальных цифрах в [[sprints/баланс-и-монетизация]].

### Android
Нужен не только для публикации, но и для записи ежедневных вертикальных роликов (см. [[sprints/04-следующий-спринт-делегирование-роликов]]).

### Маркетинг
После выхода — регулярная публикация коротких летсплеев вокруг самого игрового процесса, без отдельного производства контента.

## Что сознательно откладывается
- **Daily-система**: идеи дня, чертежи, ежедневные задания, экономика дейликов — после проверки основного цикла.
- **Продвинутый ПРО**: дополнительные деформации, редактор колёс, продвинутые инструменты.
- **Социальные функции**: команды, подписчики, совместные события, лента работ.

## История с дедушкой — убрана полностью (решено 2026-07-17)
Не отложена, не перенесена — **убрана насовсем**. Никаких вступительных слайдов о пропавшем дедушке-автодизайнере, ни в каком виде. Функцию "помочь игроку понять, что делать" полностью закрывают Референсы и Академия — оба без сюжетной/персонажной рамки, чисто справочный материал.

## Дальнейшее развитие (после того как основной цикл подтверждён)
- **Академия** постепенно превращается в библиотеку автомобильного дизайна: история стилей/моделей, интервью дизайнеров, статьи, видео, разборы пропорций.
- **Лучшие работы игроков** по каждому стилю — мотивация, первая социальная механика, признание авторов.
- **Сайт Академии** — материалы Академии, статьи, интервью, блог, лучшие работы.
- **Бесплатные PDF**-шаблоны — материал Академии, лид-магнит для email-подписки, инструмент обучения.
- **Email-сообщество** — не зависит от алгоритмов соцсетей, новости проекта/стилей/Академии.
- **3D-печать** — сначала автор печатает лучшие модели игроков как призы; полноценное производство/продажа — только после того, как игра станет устойчивым продуктом.

## Главная идея проекта
Игра постепенно перестаёт быть просто редактором автомобилей и становится инструментом, который помогает видеть красоту автомобильного дизайна, понимать стили, замечать пропорции, развивать чувство формы, создавать собственные идеи. Академия, референсы, обучение, шаблоны, сообщество и будущая 3D-печать — естественное продолжение этой идеи.

## Что меняется относительно решений, записанных ранее 2026-07-17
- **Отменяется:** последовательное открытие стилей с нарративным гейтом (Storyline-экран, Orders-уровни по чертежам, звёзды-порог) — промежуточное решение того же дня, заменено этой концепцией. Причина отмены — прямое противоречие с "Workshop открыт практически сразу" и с находкой из отзывов про долгий путь к реальной игре.
- **Отменяется:** пейвол Workshop ($2) полностью, не просто "стал бесплатным базовым режимом" — теперь это осознанная часть монетизационной стратегии, не техническая деталь.
- **Уточняется:** ПРО v1 включает выбор среди уже существующих базовых схем деформации (не Безье-кривые) — не противоречит более раннему решению не строить продвинутый выбор схем в v1, просто конкретизирует объём v1.
- ✅ **Закрыто 2026-07-17:** открытие стилей — **свободное по порядку** (не последовательное). Промежуточный разворот на последовательное открытие в течение того же дня — отменён.
- ✅ **Закрыто 2026-07-17:** история с дедушкой убрана полностью, не перенесена в Академию даже фрагментом — см. раздел выше.

## Экономическое следствие отмены пейвола
Исторический когортный LTV (см. [[sprints/баланс-и-монетизация]], раздел "Прогноз") на 79.5% состоял именно из дохода пейвола Workshop. Прогноз $3200-16000/год уже был посчитан **без учёта пейвола** (на данных "LTV без пейвола"), так что полная отмена пейвола не меняет уже сделанный прогноз — скорее подтверждает, что закладываться нужно было именно на эту, более скромную базу, а не на исторический доход, который включал пейвол.
