# Промокоды из роликов: чертёж-паззл на главном экране

Связано с: [Промокоды — серверный дизайн](07-промокоды-сразу-параллельно.md) · [Контент-конвейер](../inspiration/01-контент-конвейер-ролики-и-инспирация.md) · [Чертежи-коллекции (другая механика, не путать)](11-чертежи-коллекции.md)

⚠️ Не путать с [[11-чертежи-коллекции]] — там "чертёж" это игровой режим сборки по референсу. Здесь "чертёж" — визуальная метафора для UI коллекции промокодов (паззл-контур, заполняется кусочками).

## Механика
- Генерация кодов привязана к контент-плану роликов — скрипт роликов сам решает, какой код в каком дне, расписание уходит на сервер вместе с планом публикаций.
- **~12 кодов/месяц, делятся пополам:** 6 идут в чертёж обвеса, 6 — в чертёж детали корпуса.
- **Обвес: сетка 3×2 = 6 кусочков** → собирается за ~1 месяц. **Деталь корпуса: сетка 4×3 = 12 кусочков** → за ~2 месяца. Сетка фиксированная (два статичных префаба, не рантайм-генерация под произвольное N) — визуально лист чертежа A0, собираемый из листов A4.
- **Срок годности кода: 3 дня, одинаково для обоих типов.** Если код в конкретном ролике истёк — в профиле/канале смотришь **3 последних ролика**, среди них гарантированно 1-2 живых кода. Это отвязывает получение кода от того, какой именно ролик показал алгоритм и когда (не наказывает за задержку алгоритмической раздачи), и не даёт нафармить весь архив разом — тот же принцип, что у Twitch Drops (не засчитывают просмотр записи, только текущее окно).
- Контент для призов зарезервирован заранее: в основном обвес (Экстрас), иногда новые формы корпуса.
- **Опционально, не для v1:** истёкший код даёт скромную утешительную награду (немного монет), не кусочек паззла — старый архив не совсем бесполезен, но дефицит главного приза не подрывается.

## UI
- Кнопка "Чертёж" на главном экране.
- Экран с двумя чертежами-паззлами одновременно (деталь + обвес) — введённый код добавляет недостающий кусочек контура; сервер сам знает, в какой чертёж идёт кусочек.
- Ввод кода: 6 цифр, по одной на ячейку, группировка 3+3 через пробел, цифровая клавиатура.
- Визуал сборки — сетка ячеек поверх картинки детали (лист A0 из листов A4), незаполненная ячейка = тёмный оверлей + замок, плюс отдельный ряд из N кружков-индикаторов прогресса под картинкой. Анимация открытия — кусочек "прилетает" в свою ячейку (0.3-0.4с) + короткий scale-pop, оверлей гаснет. Награда — салют + попап.
- Полученная деталь помечена значком "промо" — переиспользует существующий механизм пометки (Экстра/Премиум), нужна только новая сущность-тип.
