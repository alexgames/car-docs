# Продуктовые гипотезы — индекс

Связано с: [Описание проекта](../00-описание-проекта.md) · [Роадмап на год](../01-роадмап-год.md) · [План тестирования](../07-план-тестирования.md)

Каждая гипотеза — отдельный файл в этой папке по шаблону:

```
## Гипотеза
Если сделаем X, то метрика Y изменится на Z, потому что ...

## Статус
идея / в работе / проверена: подтверждена / проверена: опровергнута

## Как проверяли
...

## Результат
...
```

## Текущий фокус (не гипотеза, а инцидент/задача)
По [аудиту аналитики](../05-аудит-аналитики-2026-07-06.md): реальные транзакции остановились 14 марта 2026 при живой аудитории (~60 активных пользователей/мес). Владелец решил не выделять это в отдельный аврал, а закрыть в рамках общей проверки robust-версии (см. [[../07-план-тестирования]]) — но не терять из виду.
